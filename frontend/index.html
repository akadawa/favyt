Connect your YouTube account via Google API to automatically sync your Liked Videos (Favorites) and Playlists.

Quick Guide for Google API Credentials:

  1. Go to the Google Cloud Console.
  2. Under APIs & Services, enable the YouTube Data API v3.
  3. Under Credentials, create an OAuth 2.0 Client ID (Web Application).
  4. Add as Authorized Redirect URI:
    http://localhost:8245/api/auth/callback (or your NAS address)
  5. Enter the Client ID and Client Secret above & click Sign In.
